# Do Not Tamper — Custom Sticker Tool

An interactive, browser-based generator for the "Do Not Tamper" sticker from
*Death Stranding*. Tweak the title, serial number, tracking codes, accent color,
and holographic gradient theme, then export the result as PNG or SVG.

Based on the original [CodePen pen by Richard Rose](https://codepen.io/maneatingfish/pen/KKpZagG) (MIT).
